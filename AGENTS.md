# Agent Guide

Orientation for agents (and humans) working in this repo. Detailed docs live in the files below — this file is just the index.

## Start here
- [README.md](README.md) — what arena-docs is: the ARENA Documentation website (Jekyll static site), deployed to [docs.arenaxr.org](https://docs.arenaxr.org).
- [index.md](index.md) — site landing page.

## Conventions & development rules
- [CONTRIBUTING.md](CONTRIBUTING.md) — mandatory rules for all contributors, **including agents**: development conventions specific to this repository.

## Site content
The [content/](content/) directory contains the documentation pages organized by topic:
- `content/overview/` — high-level ARENA overview and getting started.
- `content/architecture/` — system architecture documentation.
- `content/interface/` — web interface and user interaction.
- `content/3d-content/` — 3D content creation and management.
- `content/programs/` — ARENA programs and application development.
- `content/python/` — Python SDK tutorials and guides.
- `content/python-api/` — auto-generated Python API reference.
- `content/unity/` — Unity SDK documentation.
- `content/schemas/` — schema documentation (message format, object types, attributes).
- `content/tools/` — ARENA tools documentation.
- `content/xr/` — XR (extended reality) requirements and guides.
- [content/troubleshooting.md](content/troubleshooting.md) — troubleshooting guide.

## Build scripts
- [scripts/README.md](scripts/README.md) — documentation generation scripts for auto-generating API reference and schema docs.
